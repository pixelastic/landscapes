# landscapes

> **⚠️ ARCHIVED**: This website displays archived data from the r/EarthPorn subreddit. The data collection has been discontinued as of January 19, 2023 due to the underlying Reddit API no longer being available.

## Archive Information

- **Archived Date**: October 19, 2025
- **Last Data Update**: January 19, 2023
- **Data Source**: [landscapes-data](https://github.com/pixelastic/landscapes-data) (also archived)
- **Status**: Website remains online for historical reference with frozen data

---

This repository holds the code for the
[https://projects.pixelastic.com/landscapes/][1] website. The website is generated
by [norska][2], with the [search-infinite][3] theme.

The data is crawled daily from reddit using [reddinx][4], then pushed to
[Algolia][5]. The code of that part is available on the [landscapes-data][6]
repository.
